# QA check (after, diff, тріаж)

Мета: показати, що змінилось на сайті після змін і чи це збігається з тікетом. Інструмент: `<dops_cli> visual` з профілю `.claude/dops/project.md`.

## Передумови

1. **URL set і середовище:** як у `dops:qa-start`; середовище те саме, що в baseline. Віддалені лише за моїм явним запитом, production без окремого рішення не знімай.
2. **Baseline:** `<toolkit_dir>/<visual.outputDir>/<visual_set>/<TICKET>-before/meta.json`. Якщо його немає, скажи одним рядком і запропонуй `dops:qa-start`. Порівнювати нема з чим, не імітуй порівняння.
3. Зміни мають уже працювати в середовищі, яке знімається (кеш почищено). Якщо не впевнений, спитай.

## Кроки

1. **Зняти «after»** тими самими сторінками:
   `<dops_cli> visual capture <visual_set> -l <TICKET>-after --like <TICKET>-before`
   Якщо `<TICKET>-after` уже є, спитай, і лише за згодою додай `--force`. Якщо триває понад хвилину, запусти у фоні й повідом.
2. **Порівняти:**
   `<dops_cli> visual compare <visual_set> --before <TICKET>-before --after <TICKET>-after`
   Код виходу: `0` без змін, `1` є зміни, `2` є зламані сторінки.
3. **Зламані сторінки** (код 2, рядки `broken`): сторінка не завантажилась (4xx/5xx, помилка навігації, блокування переходу, сторінка фатальної помилки), навіть якщо так само було й у baseline. Для таких сторінок порівняння не є успіхом: вердикт «зламане середовище», не «чисто».
4. **Тріаж.** Відкрий HTML-звіт (`report-<before>-<after>.html`) або для найбільших змін (не більше 5) diff-зображення з `diff-<before>-<after>/` і after-скрін (Read). Порівняй із тікетом. Класифікуй:
   - **ОЧІКУВАНА**: збігається з тим, що просить тікет;
   - **НЕСПОДІВАНА**: не стосується тікета або виглядає як поломка;
   - **ШУМ**: динамічний вміст (дати, банери, лічильники, відео). Запропонуй CSS-селектор для `visual.hide`, але сам не змінюй.
5. **Кеш.** Якщо «after» не відрізняється від «before» там, де зміни мали б бути видимі, не вважай це успіхом: перевір, чи зміни справді в цьому середовищі, чи почищено кеш і чи ввімкнено `visual.cacheBust`.

## Формат виводу (до ~15 рядків)

1. **Вердикт** (1-2 речення): чисто / є несподівані зміни / зламане середовище. «Чисто» лише без зламаних сторінок.
2. **Таблиця:** сторінка, клас, коментар.
3. **Зламані сторінки** з причиною.
4. **Пропозиції для `visual.hide`.**
5. **Не покрито:** back office, листи, сайти й сторінки поза набором.

## Правила

- Не оновлюй baseline, не лагодь код і не змінюй конфіг без мого прохання.
- Розділяй ФАКТ (diff, статуси) і ГІПОТЕЗУ (чому так).
- Це свідчення, а не доказ відсутності регресій.
