# Test content (лише через UI)

Створює тестовий контент так, як це зробив би редактор: вхід у back office у браузері Playwright і заповнення форм.

## Правила

- **Лише за явним запитом**, де названо середовище. Середовища беруться з `remote_test_envs` профілю. Хости з `production_hosts` не відкривай ніколи.
- **Лише UI**: Playwright через back office. Жодних drush, SSH, SQL чи API-викликів до цього середовища.
- **Обмеж навігацію**: блокуй будь-який перехід (і редирект) на хост поза `remote_allowed_hosts` і записуй фінальний URL кожної дії. Тестове середовище може переадресувати на production.
- **Секрети**: читай із `credentials_file` профілю (`TEST_HTTP_USER`, `TEST_HTTP_PASS`, `TEST_BO_USER`, `TEST_BO_PASS`, необов'язково `TEST_BO_PASS_FALLBACK`). Використовуй лише всередині коду Playwright. Ніколи не повторюй їх у чаті, файлах, документах чи комітах. Якщо ключа бракує, попроси мене додати його у файл, а не вставляти в чат.
- Контент лише **додається**: не змінюй і не видаляй чужий контент. Якщо тестовий контент для цього тікета вже є, не чіпай його й повідом.
- Тестовий контент лишається після задачі. Не прибирай без прохання.
- Браузер видимий.

## Вхід у back office

Якщо `TEST_BO_PASS` не підходить, спробуй `TEST_BO_PASS_FALLBACK` один раз, якщо він заданий, і повідом, який спрацював. Якщо обидва не підходять, зупинись і спитай: невдалі спроби блокують обліковий запис (у Drupal за замовчуванням після 5).

## Процедура

1. **Спершу перевір кожне середовище** (лише читання), окремим browser context:
   - `browser.newContext({ httpCredentials: { username, password, origin } })`, відкрий `/user/login`, заповни `name` і `pass`, відправ форму;
   - перевір, що функція тікета задеплоєна;
   - відкрий форму створення потрібного типу контенту й перевір, що потрібні поля є;
   - пошукай наявний тестовий контент у `/admin/content?title=<KEY>`;
   - про блокери (вхід, функція не задеплоєна, бракує поля) повідом до створення будь-чого.
2. **Створи контент через форми.** Назви:
   - заголовки `<KEY> TEST <role> <case>`;
   - URL alias `/<key-lowercase>-test/<slug>`;
   - публікуй, якщо випадок не потребує неопублікованої сторінки.
3. **ID вузлів бери зі списку контенту**, а не зі збереженої сторінки: `/admin/content?title=<exact title>`, посилання `/node/<id>/edit` рядка з точним заголовком.
4. **Перевір** як анонімний відвідувач: `curl -s -u "$USER:$PASS" -o /dev/null -w '%{http_code} -> %{redirect_url}'`. Перед показом прибери креденшіали, які curl повертає в `redirect_url`.
5. **Вийди** (`/user/logout`, підтвердження `#edit-submit`) і видали збережений storage state Playwright.
6. **Звіт** англійською, таблиця на кожне середовище: випадок, що введено або перевірено, ID вузлів, test URLs, результат. Якщо прошу, додай URL у звіт тікета `dops:task-report` у розділ **Test URLs:**.

## Підводні камені форм Drupal

- **Згорнуті секції**: поля всередині закритих `<details>` (групи полів, бічна панель з URL alias) приховані. Відкрий кожного закритого предка кліком по `summary`, інакше Playwright чекає на приховане поле до таймауту.
- **Обов'язкове медіа**: якщо поле media library обов'язкове, відкрий діалог кнопкою `[data-drupal-selector$="open-button"]`, відміть перший `.js-media-library-item input[type=checkbox]`, натисни першу `.ui-dialog-buttonset button`, дочекайся вибору, потім зберігай.
- **ID на збереженій сторінці ненадійний**: у сторінок з alias немає shortlink, а розмітка містить посилання на інші вузли. Бери ID зі списку контенту.
- **Зберегти**: `#edit-submit`; публікація: `input[name="status[value]"]`.
- **Redirect для наявної сторінки** вказуй як `node/<id>`, а не alias: модуль Redirect перетворює alias на `node/<id>` до перевірки, і redirect з alias ніколи не спрацює. Перше збереження покаже попередження про валідний шлях, натисни `#edit-submit` ще раз.
- **Autocomplete**: вводь через `pressSequentially`, а не `fill`, і чекай ~3 с. Читай лише видимі `ul.ui-autocomplete li`. Текст, що починається з `/`, підказок не викликає.
- **Мова back office різна** на різних середовищах: шукай кнопки й поля за name, id або `data-drupal-selector`, не за текстом мітки.
