# Ticket start (оркестратор)

Ти лише з'єднуєш окремі skills у потік. Не змінюй їхню поведінку і не дублюй їхній вивід.

## Кроки

1. **Аргументи.** Тікет (обов'язково; якщо немає, спробуй взяти з назви поточної гілки, інакше спитай), прапорець `--no-qa`, необов'язкове середовище.
2. **Аналіз.** Виклич `dops:task-history` для цього тікета. Покажи його результат.
3. **Baseline.** Якщо є `--no-qa`, на цьому зупинись. Інакше перевір умови:
   - URL set `visual_set` з профілю описаний у `dops.config.yml` toolkit;
   - середовище: локальне за замовчуванням; віддалене лише якщо я передав його аргументом;
   - зміни тікета ще не потрапили в це середовище.

   Якщо все виконано, виклич `dops:qa-start` для цього тікета (він знімає baseline у фоні). Якщо ні, напиши одним рядком, що пропущено і чому.

4. **Підсумок одним рядком:** «Аналіз: готово. Baseline: запущено / пропущено (причина)».

## Правила

- Якщо крок падає або потребує мого рішення, зупинись і скажи. Не продовжуй мовчки.
- Не запускай нічого проти віддалених середовищ без мого явного запиту.
